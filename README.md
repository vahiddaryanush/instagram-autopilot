# اتوپایلوت اینستاگرام (رایگان و خودکار)

هر ۱۰ دقیقه GitHub Actions بررسی می‌کند و در صورت نیاز: ایده می‌سازد ← زمان‌بندی می‌کند ← عکس/ویدیو و صدا می‌سازد ← منتشر می‌کند ← نتیجه‌ی ریلزها را می‌خواند تا موضوع‌های موفق را بیشتر تولید کند.
بدون پست دستی، ۷ روز آینده همیشه پر است.

## کلیدهای لازم (همه رایگان)
| Secret | از کجا |
|---|---|
| `IG_ACCESS_TOKEN`, `IG_USER_ID` | Meta for Developers، مراحل در README پروژه‌ی قبلی (Page Token بدون انقضا + آیدی اینستاگرام) |
| `GEMINI_API_KEY` | aistudio.google.com/apikey |
| `PEXELS_API_KEY` | pexels.com/api |

`GITHUB_TOKEN` را خود گیت‌هاب می‌دهد.

## راه‌اندازی
1. ریپوی **Public** بسازید و کل پوشه را آپلود کنید (مدیا موقتاً روی شاخه‌ی `media` میزبانی می‌شود و اینستاگرام باید به آن دسترسی داشته باشد).
2. چهار Secret بالا را در Settings ← Secrets and variables ← Actions بسازید.
3. Settings ← Actions ← General ← Workflow permissions را روی *Read and write* بگذارید.
4. تب Actions ← «Instagram autopilot» ← Run workflow. اجرای اول صف ۷ روزه را پر می‌کند.

پیش‌نمایش محلی بدون هیچ کلیدی: `pip install -r requirements.txt` و بعد `python pipeline.py --demo` (خروجی در پوشه‌ی `out/`).

## شخصی‌سازی (`config.json`)
- `topic`: موضوع پیج. الان آشپزخانه و خانه (متناسب با لوگوی فروشگاه). هر چه خواستید بنویسید.
- `brand_handle`: نام کاربری که روی تصاویر چاپ می‌شود؛ درستی‌اش را چک کنید.
- `slots`: ساعت و نوع انتشار. پیش‌فرض: روزی ۱ ریلز، ۲ استوری، و ۳ کاروسل در هفته.
- `gemini_model`: اگر مدل پیش‌فرض از دسترس خارج شد، نام مدل رایگان جدید را بگذارید.
- موسیقی: فایل‌های mp3 **بدون حق‌مؤلف** را در `assets/music/` بگذارید تا با صدای کم زیر ریلز پخش شود. بدون آن، ریلز فقط گوینده دارد.

## نکته‌های صادقانه
- **تست واقعی با اینستاگرام نشده**: من رندر عکس، استوری و ریلز و منطق زمان‌بندی/انتشار را با داده‌ی ساختگی تست کرده‌ام، ولی بدون توکن شما نمی‌توانم اتصال واقعی به API را تست کنم. اگر اولین اجرا خطا داد، متن `last_error` در `queue.json` یا لاگ Actions را بفرستید.
- **صدای گوینده** با `edge-tts` ساخته می‌شود: رایگان ولی غیررسمی. اگر کار نکرد، ریلز بدون صدا ساخته می‌شود (متن روی تصویر می‌ماند)، و انتشار متوقف نمی‌شود.
- **متن‌ها را هوش مصنوعی می‌نویسد**؛ هفته‌ای یک بار صف را در `queue.json` سرسری بخوانید و موارد نادرست را حذف کنید.
- فالوور از ثبات و کیفیت می‌آید، نه از خودکار بودن. بعد از ۲ تا ۳ هفته، `metrics` ریلزها را در `queue.json` ببینید.
- روی ریپوی Public کاملاً رایگان است. در Private سهمیه‌ی ماهانه ممکن است تمام شود.
